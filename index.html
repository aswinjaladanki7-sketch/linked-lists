Operation #1

Insert Element

Select an insertion operation to add a node to the singly linked list:

Beginning (Head) Time: O(1)

Creates a new node at the front of the list and updates the HEAD pointer.

Middle (Interior) Time: O(n)

Traverses from HEAD to the specified index and splices the new node between nodes.

📌 0-Based Indexing: Position 0 is Head. Valid index range: 0 to 0.
End (Tail) Time: O(n)

Traverses the list to find the last node and connects it to the new node.

Operation #2

Delete by Value

Deletes the first matching occurrence of the specified value from the linked list.

Operation #3

Traverse Linked List

Visits each node from HEAD to the terminal NULL pointer, sequentially highlighting the active pointer.

Operation #4

Search for Value

Searches the list linearly. If found, highlights the matching node and reports its index and position.
