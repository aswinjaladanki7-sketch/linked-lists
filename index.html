Linked List & Visualizer Guide

Linked List Types Covered

  • Singly Linked List: Each node has a data field and a single next pointer pointing forward. The last node points to NULL.
  • Doubly Linked List: Each node has prev and next pointers allowing forward and backward traversal. head->prev is NULL and tail's next is NULL.
  • Circular Linked List: The last node links back to the HEAD node instead of NULL, forming a continuous cycle.

How This Visualizer Works

Unlike typical JavaScript-only animations, every operation here is executed in compiled C via WebAssembly!

  • When you click Insert, C calls malloc(sizeof(struct Node)) on its WebAssembly heap.
  • When you click Delete, C invokes free(node) to prevent memory leaks.
  • When you click Update, C traverses directly to the target node and updates its integer payload.
  • When you switch list types, C dynamically adjusts pointer links across nodes in memory.
  • The visualizer retrieves the list directly from C memory (get_serialized_list()) displaying the actual memory pointers (e.g. 0x00812018).
